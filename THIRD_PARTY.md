# Third-party sources

- **Mathlib** ([leanprover-community/mathlib4](https://github.com/leanprover-community/mathlib4)), Apache-2.0, fetched at the revision in [lake-manifest.json](lake-manifest.json). It is a build dependency; no Mathlib source is copied here.
- **OpenAI's mathematics library** ([openai/math](https://github.com/openai/math), directory `lean`), Apache-2.0, fetched as the Lake package `OAI` at commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`. It supplies the Anderson operator, the finite torus, certificate events and the `SpectralResolution` structure used in the statement. It is a build dependency; no source is copied here.
- **LeanPool** ([LeanPool/lean-pool](https://github.com/LeanPool/lean-pool)), Apache-2.0, commit `e41941e04db5ee7cce773e64203765566b04a416`. The bounded Borel functional calculus and projection-valued measure in `AndersonAC/Spectral/` are ported from its `DavisKahan/ForTauCeti/Analysis/InnerProductSpace/BorelCalculus` modules; only import paths were changed, and the original notices are kept in each file.
- **Tau Ceti** ([TauCetiProject/TauCeti](https://github.com/TauCetiProject/TauCeti)), Apache-2.0, commit `1892f4f4d83ca0f67f88a6add28b2cea82747f32`. `AndersonAC/BoundaryFinite/Nevanlinna.lean` ports its Herglotz–Nevanlinna representation and the modules it needs (Prokhorov, circle, Herglotz, Cayley, Pick), adapted to Lean 4.34.1; the original notice is kept.
